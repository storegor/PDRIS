# Лабораторная работа: Развертывание в Kubernetes

Этот проект представляет собой веб-приложение на Flask с базой данных PostgreSQL, развернутое в Kubernetes с помощью Minikube.

## Структура проекта

```
.
├── app/                  # Исходный код Flask-приложения и Dockerfile
├── k8s/                  # Манифесты Kubernetes для развертывания
├── start.sh              # Скрипт для запуска и развертывания приложения
├── stop.sh               # Скрипт для остановки приложения и очистки ресурсов
└── build_and_push_to_registry.sh # Скрипт для сборки и публикации Docker-образа
```

## Требования

Для запуска проекта на вашем компьютере должны быть установлены:
- [Docker](https://docs.docker.com/get-docker/)
- [Minikube](https://minikube.sigs.k8s.io/docs/start/)
- [kubectl](https://kubernetes.io/docs/tasks/tools/install-kubectl/)

## Быстрый старт

**Разверните приложение:**

Эта команда автоматически проверит, запущен ли `minikube`, запустит его при необходимости, развернет приложение и настроит доступ к нему.

```bash
./start.sh
```

После успешного запуска приложение будет доступно по адресу `http://localhost:8000`.

**Чтобы остановить приложение и удалить все ресурсы**, просто нажмите **Enter** в том же терминале, где был запущен скрипт `start.sh`.

## Полная остановка

Если вы хотите не только удалить ресурсы приложения, но и остановить сам кластер Minikube, выполните:

```bash
./stop.sh
```
